## Layout

```text
demo.json              # the only declaration file; everything reads this
src/                   # demo source
models/                # .cvimodel assets, if any
eval/input/manifest.json  # fixed evaluation input provenance
dist/                  # build output (gitignored)
```

## Build and verify

```bash
# cross-compile (RISC-V musl), writes dist/ and dist/build-report.json
python3 scripts/build_demo.py --demo-dir <this dir>

# host-side logic smoke test (no device, no model)
python3 scripts/smoke_demo.py --demo-dir <this dir>

# optional: fetch an official model listed in configs/model-assets.lock.json
python3 scripts/fetch_models.py --name yolo11n --out <this dir>/models

# deterministic distributable archive
python3 scripts/package_demo.py --demo-dir <this dir>
```

## Run on the device

```bash
export RECAMERA_PASSWORD='<device password>'
python3 scripts/probe_device.py --host 192.168.42.1
python3 scripts/deploy_demo.py --demo-dir <this dir> --host 192.168.42.1 --action install --replace
python3 scripts/deploy_demo.py --demo-dir <this dir> --host 192.168.42.1 --action start
python3 scripts/deploy_demo.py --demo-dir <this dir> --host 192.168.42.1 --action verify
```
